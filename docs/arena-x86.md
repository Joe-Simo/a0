# Experimental full-word A0 x86 service

`emit_x86_arena.a0` consumes the shared immutable16-word context and performs geometry, Linux/Darwin ABI decisions and assembly generation in A0. `x86_service_arena.a0` connects original source parsing, ordered body/spec verification and checked-table lowering. `x86_link_service_arena.a0` connects POSIX loading and complete linked grammar to the same verifier. The host supplies storage, OS calls and opaque continuation resumption. Public compiler routing and optimization still use TypeScript.

The service covers canonical scalar, IO, checked and aggregate operations, including full-word operands, large function/type/node directories and aliased aggregate results. A successful backend request requires terminal ordered-verifier success, not just current status0 or parser grammar completion. A linked spec-bearing parse preserves pending verification until that verifier finishes. Invalid examples, resource failures, incomplete framing and pending requests publish no output. The separate linked-verifier service carries richer selected diagnostic-origin projection; the simple x86 service retains linked metadata but does not claim that complete diagnostic renderer.

Current experimental options accept Linux/Darwin, canonical profile, IO capacities through16777216 words and options0. Strict input and other options are refused explicitly. Dense and malformed raw UTF8 module loading remain unsupported. Optimization, register allocation, ownership/copy elision, strict metadata and existing public option/performance parity remain work before this service can replace the shipped backend.

Permanent tests build the actual compiler with the verified native A0 seed. On Linux x86-64 they assemble and execute independent arithmetic, IO, checked-record, packed-aggregate and aliased-result cases, detect an instruction mutation, cross legacy metadata capacities and exercise original-source/module/error boundaries. Darwin output is cross-assembled; these tests do not establish target execution on macOS. Other hosts still build/run the A0 source-service framing and verification controls where the generic POSIX transport is available.
