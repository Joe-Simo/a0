# Experimental arena C# service

`emit_csharp_arena.a0` performs C# type/name/opcode and text decisions over the shared checked context16. `csharp_service_arena.a0` composes the ordered A0 verifier, `backend_service_arena.a0`, and that emitter. Original input bytes remain in the arena; the host transports words and repeats A0 continuations. It does not parse user source, select compiler operations, decide language fuel/trips, or fall back to TypeScript emission.

The public source API is `arena_csharp_source_begin(io,handle,byteLength)`, followed by `arena_csharp_source_resume(state,positiveQuantum)` until `arena_csharp_source_done(E)` returns true. Scheduling quantum is separate from language fuel. State is `(E128,backendService)`; E0 is status, E1 is done, and E3..5 is the output vector. Use the done function: terminal refusal7 is distinct from an unfinished continuation. `arena_csharp_source_publish` emits only a successful completed result and returns status plus the IO token. The caller must require successful FINISH and is_complete before publishing external output.

The shared frontend/lowerer owns semantic validity, complete spec verification, global IDs, topological types and padded sentinel rows. Direct `acs_emit` calls require that checked context; this is not a forged-IR validator. Target scratch remains separate from the immutable origin descriptor. Strict flag bit0 and original source iteration names are retained. Unknown opcodes refuse6 atomically. `acs_emit_options` explicitly refuses nonzero options with8. Unit imports remain an explicit7 refusal; linked C# service composition and compiler option parity are pending.

The emitter covers canonical and checked operations, arrays, public readonly record structs, persistent aggregate updates, calls/fold/loop and the existing C# public ABI. Arithmetic bodies are explicitly unchecked; checked arithmetic uses widened flags and raw unsigned indexes. Strict code carries original function/iteration names in a dynamic shadow stack and exposes the current A0Trap fields and Line format. Program IO retains the existing C# target's input256/output1024 capacities. These program ABI capacities are separate from the compiler's source/IR storage.

Type names retain the structural R_ ABI. An arena-backed iterative stack emits names, and a separate iterative walker emits array types. There is no legacy source/page/name/depth ceiling. Unrepresentable output and explicit allocation/transport failures still refuse; unfinished work at the full-u32 writer domain returns7. Vector blocks and temporary stacks live until FINISH, and there is no compiler-session garbage collector. Resource failure is explicit rather than a silent change to source acceptance.

`test/arena-csharp.test.ts` uses the shared verified-seed helper and generic arena runtime. Native generation and boundary tests run with Clang even without .NET. A separate existing-SDK test compiles canonical and strict output with project overflow checking enabled and runs independent checked arithmetic, ABI, IO-effect and exact-trap assertions. SDK absence is a skip, not target correctness evidence. Existing CI setup-dotnet is discovered through the shared optional helper. Restore uses a local empty feed; no toolchain or package installation is performed.

Native source-generation evidence and actual C# compilation/execution are separate. This experimental component is not production dispatch, optimizer-option parity, linked-service completion, or complete compiler migration.
