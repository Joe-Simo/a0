# Recovered native authoring foundation

The optional native frontend retains authoring metadata with checked ownership and exposes
formatting, revision and diagnostic services. A source-bound package loader validates its
component inventory and identities before use, then supports independent engine lifetimes.
These internal APIs do not activate a new CLI default or establish release qualification.

The existing A0S formatter and revision input paths are retained as exact passthroughs of
their A0 source, so their compatibility generation commands remain valid without deleting
previously available files. A0 source remains the implementation used for these components.

Recovered native CLI, MCP, LSP, editing and sealed graph-service integration is still being
reconciled with the newer candidate-frontend and protection interfaces. It is not activated
by this foundation. Existing session, revocation, writer and migration checks remain required.
The historical native-cost, independent AI-study, platform and protection-assurance gates
remain open; this work does not claim default cutover or a full release pass.
