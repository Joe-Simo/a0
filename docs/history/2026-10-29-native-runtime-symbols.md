# Private native trap-runtime symbols

The direct native backends used the same `a0_<name>` namespace for public functions and internal strict-trap helpers and data. A valid function named `dec` therefore collided with the decimal formatter as soon as the module needed a trap runtime. The same defect affected `cpy`, `trap`, `ts` and `tb`. All five assembly failures were reproduced on the unchanged preceding checkpoint, as recorded in [the controls](../../results/native-symbol-controls.json).

The shared trap runtime now uses assembler-local labels for its helpers, reporter and storage: `.La0r_*` on ELF and `La0r_*` on Darwin. Both direct native emitters and the x86 strict-input helper resolve those private labels consistently. Public function symbols remain `a0_<name>` on Linux and `_a0_<name>` on Darwin; the fix does not reserve valid source names or change the public calling convention.

Regression cases execute the formerly colliding functions, nested calls and folds, exact strict bounds diagnostics, and input exhaustion through a public `trap` function. Both optimized and unoptimized native outputs run through the existing interpreter-oracle harness. The same programs cross-assemble to Linux x86-64, Darwin x86-64 and Darwin ARM64 objects on Linux. Cross-assembly is not Darwin execution validation.

The [output audit](../../results/native-symbol-controls.json) checks 580 unchanged stock-kernel/profile/optimization/target combinations against the preceding checkpoint, allowing only the intended native runtime-label renaming. All 58 checked Linux native objects retain identical executable-section bytes. Object sizes and assembly text lengths are recorded explicitly; longer private names can enlarge assembly text even though instructions do not change. Across the 29 strict Linux objects, total object-file bytes change from 79048 to 76088 while executable sections remain 48181 bytes. The 29 canonical object files remain 49904 bytes. These object totals include metadata and are not a single application size. No runtime, compilation-speed or memory improvement is claimed. Earlier unfavorable compilation measurements remain in the preceding milestone's evidence.

The final version-only snapshot control, seed proof and available aggregate gate are preserved with the recovery archives. Full-platform release validation remains outstanding. Publication and private uploads still await approval; neither denied operation was retried.

The first aggregate attempt exposed an [oracle assumption](../../results/native-symbol-oracle.json): Clang strips assembler-local BSS symbols, so an existing name lookup failed after the byte and relocation checks passed. The corrected oracle retains local symbols for name comparisons, and also assembles normally to assert identical text bytes and text/BSS sizes. Existing relocation and BSS offset checks remain. The stopped attempt and corrected focused results are preserved separately.
