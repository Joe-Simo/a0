A0 guide. Program = functions; each: `fn NAME T... -> T`, lines `ID OP OPERAND...`, `ret OPERAND`, `end`.
Types: u32 bool io, arrays Tx4, records (u32,bool); nest without spaces. Params are p0 p1 ...
Operands: earlier ID in this function, pN, decimal u32, true, false. IDs [a-z][a-z0-9_]*. # comment.
No forward refs, no recursion, no memory. All ops are exact and total.
OPS
 mov x | add sub mul (mod 2^32) | and or xor | shl a n = a<<(n&31) | shr a n = a>>>(n&31) logical
 div a b (b=0 -> 4294967295) | rem a b (b=0 -> a) | eq lt (unsigned) -> bool | select c x y (both computed)
 call F a...   F defined EARLIER; args match F's params; result = F's result type
 fold F n s a...   state=s; for i in 0..n-1: state=F(state,i,a...); F: (state,u32,a...) -> state
 loop P F n s a... fold that stops before iteration i when P(state,i,a...) is false; P: F's params -> bool
 arr e... | rec e... | text "utf8" (=arr of bytes; escapes \n \t \" \\) | get a i (i mod N) | set a i v (copy)
 at r k (k literal) | put r k v (copy). Aggregates are values; nothing aliases or mutates.
IO: token type io, passed as at most one parameter, each token value used once, order of use = order of effects.
 read t -> (u32,io) (0 when input exhausted) | write t v -> io | puts t a -> io (length word then elements)
 Return the token inside a record like (u32,io) when the caller continues the stream. No io in arrays or select.
EDITS: reply with the shown handle line, then edit lines. Function handle e0: `id op ...` replaces or inserts
 before ret; `id op ... @ other` inserts after other; `-id` deletes; `ret x` sets the result; trailing
 `fn name T... -> T end` lines in a view are callable signatures. Program handle g0: whole `fn ... end`
 blocks add or replace functions; `-fn name` removes. Patch form: `patch NAME SHA256` + edit lines + `end`.
EXAMPLE (p0*p1+p2 mod 2^32):
fn affine u32 u32 u32 -> u32
a mul p0 p1
b add a p2
ret b
end
