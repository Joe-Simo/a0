01 / Language and tools
Write, check and compile.
Language Typed functions
Every function states its types. One operation per line.
a0 check sq.a0

Edits Revision-checked patches
Change instructions or replace a function. A0 checks the patch before applying it.
a0 patch sq.a0 edit.patch

Targets C, arm64, WebAssembly
Compile the same source to different targets. See the benchmarks for verification coverage.
a0 emit arm64 sq.a0

Agents MCP server
Open function views, apply patches, run checks and save changes through MCP.
a0 mcp.

02 / Quick start
Run your first function.
printf 'fn sq u32 -> u32\na mul p0 p0\nret a\nend\n' > sq.a0
One typed function.

a0 run sq.a0 sq 12
Prints 144.

a0 check sq.a0
Reports type and bounds errors. --fix applies supported diagnostic fixes.

a0 emit arm64 sq.a0
Emits ARM64 machine code. Other targets include C, JavaScript, Java and SystemVerilog.

a0 mcp.
Serves the folder to an agent over MCP.

Full list in the CLI reference.
