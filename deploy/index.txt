01 / What A0 is
A typed language built for model edits.
Language Typed, explicit, short
Every function states its types. One operation per line.
a0 check sq.a0

Edits One function, checked
A patch replaces one function; A0 re-validates the program or rejects the patch with a diagnostic.
a0 patch sq.a0 edit.patch

Targets C, arm64, WebAssembly
One front end; the same behaviour table runs on every target.
a0 emit arm64 sq.a0

Agents MCP server
Models read, edit and check A0 through tools instead of raw text.
a0 mcp.

02 / A minute with A0
From install to a checked edit.
printf 'fn sq u32 -> u32\na mul p0 p0\nret a\nend\n' > sq.a0
One typed function.

a0 run sq.a0 sq 12
Prints the square.

a0 check sq.a0
Reports type and bounds errors. --fix applies the exact fixes.

a0 emit arm64 sq.a0
A0's own machine code; also c, js, java, sv.

a0 mcp.
Serves the folder to an agent over MCP.

Full list in the CLI reference.
