Why it matters for AI agents
Cost per edit
Short programs, one-function edits: the agent never rewrites the file around a change.

Every edit checked
The whole program is type-checked before an edit lands. A broken edit goes back to the model as an error, not into your code as a bug.

Honest limits
No floats, heap or recursion: use C, Rust or TypeScript for those. Slower than C on some programs (results/exec-benchmark-full.json); the sections below show every loss.

Next: Where A0 is slower than C

Where A0 is slower than C
A0 is slower than the best of C, Rust and Zig on 8 of 19 test programs, by up to 4.31x on mat4. Over all of them its machine code takes 1.16x as long as hand-written C, a geometric mean (on an Apple M3; results/exec-benchmark-full.json).
In WebAssembly, A0 takes 1.1x to 1.3x clang's time per loop trip on 5 of 19 kernels (results/wasm-benchmark.json).

Speed is not the point; edits are. What does an edit cost?

How much does an edit cost?
On a one-function file A0 costs 2.42x TypeScript's tokens, because the instructions dominate. Over a session of 10 edits it costs 184 tokens per task in its canonical form and 117 in its dense form (place 12 and 1 of 49 languages, 1 = fewest); results/ai-edit-b48-dense.json and results/ai-edit-experiment.b.sonnet-min.json.

How quickly do I know an edit is wrong?
A0 applies a model's edit and type-checks the whole program in 0.51 ms at the median. TypeScript with a warm compiler takes 15.1 ms (results/edit-loop.json).
