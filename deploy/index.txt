A0
for AI

A small language AI models can edit without breaking your build.
A0 is a compact language with exact rules. A model reads only the functions an edit touches, and an edit that would not compile is rejected before it lands.

b add a p2

end

Is it as fast as C?
On an Apple M3, A0's machine code takes 1.16x as long as hand-written C, a geometric mean over the test programs. It loses on 8 of 19: slower than the best of C, Rust and Zig, the worst by 4.31x on mat4 (results/exec-benchmark-full.json).

How much does an edit cost?
Over a session of 10 edits A0 costs 184 tokens per task in its canonical form and 117 in its dense form (place 12 and 1 of 49 languages, 1 = fewest). On a one-function file it costs 2.42x TypeScript's tokens, because the instructions dominate (results/ai-edit-b48-dense.json, results/ai-edit-experiment.b.sonnet-min.json).

How quickly do I know an edit is wrong?
A0 applies a model's edit and type-checks the whole program in 0.51 ms at the median. TypeScript with a warm compiler takes 15.1 ms (results/edit-loop.json).

Try it
# one binary, no package manager
 # macOS and Linux: pick the binary for your machine, a0-darwin-arm64, a0-darwin-x64, a0-linux-arm64 or a0-linux-x64
curl -L https://github.com/Joe-Simo/a0/releases/latest/download/a0-linux-x64 -o a0 && chmod +x a0
# Windows, PowerShell: a0-windows-x64.exe, then use.\a0.exe where this page says./a0
Invoke-WebRequest https://github.com/Joe-Simo/a0/releases/latest/download/a0-windows-x64.exe -OutFile a0.exe
printf 'fn sq u32 -> u32\na mul p0 p0\nret a\nend\n' > sq.a0
./a0 run sq.a0 sq 12 # 144
./a0 emit arm64 sq.a0 # A0's own machine code; or x86_64, c, js, java, sv
./a0 check sq.a0 # diagnostics with the fix

Words used here
Test case: one input with its known correct output.
Oracle: a separate, simple calculator (plain BigInt arithmetic) whose answers every target must match.
Target: what A0 compiles to: machine code, C, wasm, JavaScript, JVM,.NET, Metal, SystemVerilog.
Handle: a revision token. An edit that names an old handle is refused, so a stale edit cannot overwrite newer code.
View: the text a model is shown. A scoped view holds one function plus the signatures it calls.
Dense view: an optional shorter spelling of the same program, with fewer tokens.
Test program: one small function written in every language and timed.
Generic cell: a basic logic gate or register in the hardware output, before mapping to any chip.
