How it works.

03 The file changes only if it passes.

Where it loses.

Slower than the best of C, Rust and Zig on 8 of 19 programs.

Unsigned integers, booleans and fixed arrays. No floats, heap or recursion; for those, use C, Rust or TypeScript.
