A0 is a small language for code an AI agent edits one function at a time, each edit checked before it lands; it has no floats, heap or recursion, so use C, Rust or TypeScript for those.
Slower than the best of C, Rust and Zig on 8 of 19 test programs. On a one-function file it costs 2.42x TypeScript's tokens.
fn affine u32 u32 u32 -> u32
a mul p0 p1
b add a p2
ret b
end

Install and connect
A0 is one binary with no package manager. Install it, then connect your agent.
macOS and Linuxcurl -fsSL https://raw.githubusercontent.com/Joe-Simo/a0/main/install.sh | sh

Windows, PowerShellirm https://raw.githubusercontent.com/Joe-Simo/a0/main/install.ps1 | iex

Connect your agent
Claude Code: add the a0 MCP server with this one line. The a0 binary must be on PATH.
claude mcp add a0 -- a0 mcp.

Targets: machine code, C, wasm, JavaScript, JVM,.NET, Metal and SystemVerilog. 5262 test cases ran on 10 paths. The native assembly targets ran the 4297 that need no input or output, and SystemVerilog is simulated separately on 5262 (results/verification.json).

Works? Then see where A0 loses: Where A0 is slower than C

Where A0 is slower than C
A0 is slower than the best of C, Rust and Zig on 8 of 19 test programs, by up to 4.31x on mat4. Over all of them its machine code takes 1.16x as long as hand-written C, a geometric mean (on an Apple M3; results/exec-benchmark-full.json).

Speed is not the point; edits are. What does an edit cost?

How much does an edit cost?
On a one-function file A0 costs 2.42x TypeScript's tokens, because the instructions dominate. Over a session of 10 edits it costs 184 tokens per task in its canonical form and 117 in its dense form (place 12 and 1 of 49 languages, 1 = fewest); results/ai-edit-b48-dense.json and results/ai-edit-experiment.b.sonnet-min.json.

Cheap only if it is also caught: How quickly do I know an edit is wrong?

How quickly do I know an edit is wrong?
A0 applies a model's edit and type-checks the whole program in 0.51 ms at the median. TypeScript with a warm compiler takes 15.1 ms (results/edit-loop.json).
