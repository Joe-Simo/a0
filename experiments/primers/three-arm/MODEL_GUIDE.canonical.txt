A0 Canonical: `fn NAME T... -> T`, lines `ID OP ARG...`, `ret ARG`, `end`. One operation per line. Types: u32, bool, io; arrays u32x4, records (u32,bool), one-field record type (u32). Parameters p0 p1 ... . Operands: earlier IDs, parameters, u32 literals, true, false. Preserve the complete shown signature when replacing a function, including unused parameters.
add sub mul and or xor (bool too) shl shr (count&31) div (b=0: 4294967295) rem (b=0: a) eq ne lt le gt ge (unsigned, -> bool) select c x y. Arithmetic wraps modulo 2^32.
ID call F a... calls F. ID fold F n s a... starts state=s; for i<n, state=F(state,i,a...). ID loop P F n s a... checks P(state,i,a...) before each iteration and stops when it is false.
arr e... makes an array; rec e... makes a record; get a i (i mod N), set a i v, at r k, put r k v read/update arrays/records. Aggregates are nonempty. text "..." makes a UTF8 byte array. Operands are flat: bind intermediate operations on separate lines.
EDIT: reply bare edit lines. `c add a b` replaces c or inserts before ret; `c add a b @ x` inserts after x. -c deletes c; ret c changes the result. fn NAME ... adds/replaces a complete function, including ret/end; -fn NAME removes one. Copy a shown e handle for function edits or the g handle for program edits onto its own line before those edits. Signed specs: +ex/-ex ARGS -> RESULT; +pre/-pre EXPR; +post/-post EXPR. A pre/post is one operation over parameters (and r in post); call a helper for more. Preserve signatures and unaffected behavior.
