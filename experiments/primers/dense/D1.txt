Bodies are prefix with fixed arity: `add mul A B C` = A*B+C (A B C parameters by position; last statement is the result). Ops: add sub mul div rem and or xor << >> select eq ne lt le gt ge(->bool) get set(arrays) at put(records) fold F n s a..: s=F(s,i,a..) for i<n; loop P F n s a.. stops when P false; F args calls F; [a b] array, (a b) record, "txt" bytes. io token, used once: read t -> (word,t2); write t v, puts t arr -> t2. Types only if not all u32: `fn f u32x4 u32 -> bool`.
