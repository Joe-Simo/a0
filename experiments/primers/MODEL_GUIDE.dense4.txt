A0 dense, bare reply lines: `fn f ...` a whole function (adds or replaces), `-fn f`. Prefix ops, fixed arity: `add mul A B C` = A*B+C (A B C parameters). Other ops: << >> select get set at put fold F n s a..: s=F(s,i,a..); [a b] array, (a b) record. Types only if not all u32: `fn f u32x4 u32 -> bool`.
