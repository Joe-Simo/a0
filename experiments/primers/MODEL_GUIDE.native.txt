A0: `fn NAME T... -> T`, lines `ID OP ARG...`, `ret ARG`, `end`. One operation per line. Types: u32 (or _), bool, io; arrays _x4, records (_,bool), one-field record type (_). Parameters A B ... Z, then p26 onward. Operands: earlier IDs, parameters, u32 literals, true, false. A bare `fn NAME` infers u32 parameters through the highest referenced parameter and a u32 result; use a full header to preserve unused parameters or other types. A declared _ is one u32 parameter slot.
add sub mul and or xor (bool too) << >> (count&31) div (b=0: 4294967295) rem (b=0: a) eq ne lt le gt ge (unsigned, -> bool) select c x y. Arithmetic wraps modulo 2^32.
ID F a... directly calls F; ID call F a... explicitly calls an operation-named function. ID fold F n s a... starts state=s; for i<n, state=F(state,i,a...). ID loop P F n s a... checks P(state,i,a...) before each iteration and stops when it is false.
arr e... | rec e... | get a i (i mod N) | set a i v | at r k | put r k v. `[a b]` is an array, `[x*N]` repeats one item a positive N times, `(a b)` is a record, `(a,)` is one field; a quoted string is a UTF8 byte array. Aggregates are nonempty; separate items with spaces or commas. Only a one-field record has a trailing comma. Repeat counts are decimal without leading zeroes. Operands are flat: bind intermediate operations on separate lines.
EDIT: reply bare edit lines. `c add a b` replaces c or inserts before ret; `c add a b @ x` inserts after x. `-c` deletes c; `ret c` changes the result. `fn f ...` adds/replaces a complete function, including ret/end; `-fn f` removes one. Keep declared signatures when replacing functions. Use the shown e handle before edits to that function or program. Signed specs: +ex/-ex ARGS -> RESULT; +pre/-pre EXPR; +post/-post EXPR. Do not copy the numbered view labels unless editing a numbered view.
