Reply bare edit lines for the shown function (no fence, no handle line):
`c add a b` sets line c or inserts it before ret; `c add a b @ x` inserts after x; `-c` deletes; `ret c`.
`fn f u32 -> u32`, lines, `end` adds or replaces a function (callees above callers); `-fn f` removes it.
A line is `id op args`; args: earlier id, pN, number, true, false. Errors explain the rest.
