fn r_int io u32 u32 -> io
q div C 100
rr rem C 100
inc select ge rr 50 1 0
rounded add q inc
r putnum A rounded

fn r_one io u32 u32 -> io
tn div C 10
rr rem C 10
inc select ge rr 5 1 0
rounded add tn inc
q div rounded 10
b write putnum A q 2
dot "."
c puts b dot
td rem rounded 10
ch add td 48
write write write c 2 1 ch
