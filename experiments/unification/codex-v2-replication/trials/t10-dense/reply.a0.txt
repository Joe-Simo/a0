fn r_int io u32 u32 -> io
q div C 100
tail rem C 100
up ge tail 50
inc select up 1 0
rounded add q inc
r putnum A rounded

fn r_one io u32 u32 -> io
tenths div C 10
tail rem C 10
up ge tail 5
inc select up 1 0
rounded add tenths inc
q div rounded 10
b write putnum A q 2
dot "."
c puts b dot
td rem rounded 10
ch add td 48
write write write c 2 1 ch
