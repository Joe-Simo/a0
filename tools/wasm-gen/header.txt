# A0 wasm32 emitter and module linker, written in A0 (DESIGN.md 7a): the port of src/wasm.ts.
# Its output for a program is byte-identical to `compile(program, 'wasm', { optimize: false })`
# (the TypeScript emitter on the unoptimized program), and with the optimizer of
# compiler/optimize.a0 and the shape analyses of compiler/shape.a0 in front of it to
# `compile(program, 'wasm')`.
#
# Per-function emission (`wachunk`, `wxfun`) follows src/wasm.ts `FunctionEmitter`: a body is built
# as a list of instructions with symbolic locals in the machine table M (see `wxg`), by a step
# machine with an explicit work stack (A0 has no recursion, and the emitter inlines small fold
# bodies, predicates and scalar callees up to INLINE_DEPTH 3 deep); `Code.finish` is
# compiler/wasm_code.a0 `wfzfin` (stackification, tees, dead stores, live-range local sharing).
# The in-place rule is `mutableHere` with the shape table's BORR column (`borrowLive`). The shape
# table `sh` (u32x128x200, compiler/shape.a0) holds per node FILL (fill run count), OWN and ARM
# (lazy select arms), OVER (`overwritesState`), BORR, as columns of 2816 words from 0, 2816,
# 5632, 8448, 11264.
#
# A chunk's output (`wachunk`): per function a record (the word counts of its POOL, META and
# CODE, then those words; see `wxfun`), then (index, stack depth, iteration bound) per function,
# the chunk's variant count and its function count; the driver concatenates every record's POOL,
# then every META, then every CODE for the linker (`walink`, mode 3). Result code 7: bodies of the
# chunk functions it writes (followed by their count) are needed, run again with them.
